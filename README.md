### 🚀 About Me

I'm a full-stack developer and founder who takes products from an empty repo to a shipped, marketed app — designing and building the backend, web client, and mobile app myself.

- 🏗️ Founding & building **Navlonix** — an AI-powered logistics freight-matching marketplace, designed and built end-to-end
- 🧠 Product-minded engineer who owns the full loop: **architecture → UX → ship → growth**
- 💼 Comfortable moving across **engineering, product, and go-to-market**
- 🎓 Computer Science @ Fırat University — learning by shipping real things
- 📍 Bursa, Türkiye
